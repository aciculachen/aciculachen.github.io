# Web logos used by index5

Each PNG has a transparent 144 × 144 pixel canvas for the existing 48 × 48 CSS pixel logo frame. Artwork is centered, keeps its aspect ratio, and is never upscaled. Originals remain one directory above and are still used by earlier pages.

To regenerate: apply EXIF orientation, convert to RGBA, thumbnail to fit 144 × 144 with Lanczos resampling, center on a transparent canvas, and save an optimized PNG. Do not crop or stretch the artwork.
